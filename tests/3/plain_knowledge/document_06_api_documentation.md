# Public API Documentation v2.1

## Getting Started
Welcome to our public REST API. This documentation is available to all developers and partners.

## Authentication
```
Authorization: Bearer YOUR_API_KEY
```

## Endpoints

### GET /api/v2/products
Returns list of products

### POST /api/v2/orders
Create a new order

### GET /api/v2/status
Health check endpoint

## Rate Limits
- 1000 requests per hour for free tier
- 10000 requests per hour for premium tier

- PHP
